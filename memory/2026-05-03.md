## Membean integration finished
- `scripts/check_membean_homework.py` parses the Membean dashboard's expectations block ("3 days with 15+ minutes of training", "X/Y days trained had N+ min", "Z total minutes of training", "Goal Reached!") plus the per-session list (`training-session-<id>-title`, `<time datetime>`, `<span class="minutes-trained">`).
- IMPORTANT: dashboard URL is `https://membean.com/dashboard` not `https://membean.com/`. The bare `/` is the public marketing site even when the user is signed in.
- Membean's authoritative count (`X/Y days...`) is trusted over the parsed session list because the visible session list sometimes omits short/partial sessions that still count server-side (saw this with Eve: list shows 38 min total, dashboard says 45 min and 3/3 days hit).
- Captured URL persistence: each kid's actual dashboard URL after init is recorded in `~/.local/share/openclaw/canvas-homework-monitor/membean-<slug>-captured-url.txt` so check runs use that URL instead of guessing.
- `scripts/run_homework_digest.py` is the merged digest entrypoint: runs Canvas + N Membean configs, drops Canvas Membean items when that student's weekly Membean is `complete`, and appends the Membean weekly status block when needed.
