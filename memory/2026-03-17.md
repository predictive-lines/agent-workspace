## Lesson Learned
- **Budget frequency column (E)**: Debt service rows use `E=12` (annual frequency). Wage/benefit rows use various frequencies. ALWAYS check existing rows' E column pattern before adding new rows.
- **Always verify after writes**: The duplicate-row issue happened because the first API call appeared to time out but actually succeeded. Need to verify row count before writing again.
- **Tiller Yearly Budget tab is volatile**: Row numbers change when categories are added/removed. Never use hardcoded row references to this tab — always use named lookups.
- **Cash Bridge December columns**: Must skip annual total columns when referencing "next month" date. The template for FY2029 does this correctly (EG→EI, skipping EH). When extending, replicate the skip pattern.
- **Text vs number comparison in Sheets**: `number < "text"` evaluates TRUE. This silently passes date filters when a "Total" header is used instead of a date.
