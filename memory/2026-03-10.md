## Analog/Asimov's → Kindle Automation

Built and deployed a bimonthly magazine delivery script.

**What it does:** Logs into analogsf.com, downloads the latest EPUB of both
Analog Science Fiction and Asimov's Science Fiction, emails them to Kindle.

**Key files:**
- Script: `~/scripts/analog-kindle.py`
- Config: `~/.openclaw/workspace/config/analog-kindle.json` (credentials, kindle email)
- State: `~/.openclaw/workspace/config/analog-kindle-state.json` (sent history, dedup)
- Logs: `~/.openclaw/workspace/logs/analog-kindle.log`

**Cron:** `0 9 8 2,4,6,8,10,12 *` — 9am on the 8th of every even month (Apr, Jun, Aug, Oct, Dec, Feb)

**Gmail OAuth:** Added `gmail.send` scope to the Google OAuth project (734807837733).
Also had to enable the Gmail API in Cloud Console for that project.
Redirect URI `http://localhost:8765/callback` added to authorized URIs.

**First run:** March 10, 2026 — sent March/April 2026 issues of both magazines successfully.
State file tracks all sent issue labels to prevent duplicates.

**Site notes:** analogsf.com is WooCommerce. Login fields: `name="log"` / `name="pwd"`.
Downloads page: `/my-account/downloads/`. Issues listed oldest→newest; script picks last Analog + last Asimov's EPUB. Download triggered by clicking link text (not page.goto).
